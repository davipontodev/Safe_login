# Safe Login 🔐

Sistema web de autenticação e gerenciamento de usuários desenvolvido com Python
## Funcionalidades

- **Cadastro e Login de Usuários:** Autenticação segura com rotas server-side em Flask.
- **Criptografia de Senhas:** Hashing de senhas utilizando `bcrypt`.
- **Controle de Acesso (Admin / Usuário):** O primeiro usuário cadastrado recebe automaticamente o perfil de `admin`, tendo acesso à listagem de usuários cadastrados no painel.
- **Interface Dark Mode:** Estilização limpa em HTML5 e CSS3.

## Tecnologias Utilizadas

- Python 3
- Flask
- SQLite3
- bcrypt
- HTML5 / CSS3
